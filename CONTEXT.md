# CueDex

CueDex is a macOS-native Codex attention router. It turns selected Codex lifecycle events into local cues without retaining prompt or response content.

## Language

**Attention Router**:
The product boundary for CueDex: it routes matching Codex lifecycle events to attention cues. It is not a hook editor, task manager, or general automation platform.
_Avoid_: Completion notifier, hook manager, agent platform

**Attention Cue**:
A local visual, sound, or spoken signal that asks the user to return their attention to Codex.
_Avoid_: Alert, message, task
